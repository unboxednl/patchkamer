# Sequencers

*Nederlandse versie: [README_NL.md](README_NL.md)*

Devices that play notes for other devices. A sequencer makes no sound of its own: it sends notes to synths, which you connect with cables. Each sequencer has its own folder here with the device file and an `AGENTS.md`.

| Device | What it does | Folder | Manual |
|---|---|---|---|
| **Chord Sequencer** | Four independent tracks (A–D) with chords, arpeggios or single notes in patterns of 1 to 16 steps; four scenes; follows the studio clock | `ChordSequencer/` | [Chord Sequencer](../../docs/sequencers/USER-MANUAL_EN.md#chord-sequencer) |
