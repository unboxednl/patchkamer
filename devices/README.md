# devices

De meegeleverde apparaten van Patchkamer: instrumenten, effecten en andere bouwstenen, gebouwd volgens het [contract](../contract/).

## Een apparaat toevoegen

Houd je aan het contract en geef het apparaat één stabiele bestandsnaam zonder versienummer. De geschiedenis staat in Git.
