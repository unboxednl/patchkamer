# tunes

*Nederlandse versie: [README_NL.md](README_NL.md)*

Ready-made sounds for devices that make sound (synths, samplers and drum devices), saved as data. Choose one from the list on a device's card, use it in a song or in your own library. Devices without a sound of their own have [presets](../presets/README.md) instead.

This folder has **47 packs with 3365 tunes**, one pack per device: 36 for synths (2848 tunes), 4 for samplers (213 tunes) and 7 for drum devices (304 tunes). A drum device loads a whole machine (sounds and pattern) as one tune. The column **Folders** is the number of style folders in the pack; their names are in the manual.

## How to use them

- Load `github.com/unboxednl/patchkamer` as a library in Patchkamer: the packs come with it. Or download a file from this folder and use the **Tunes** tab in the library (the **Library** button) → **Import…**.
- Then choose a tune in the list on the card of the device.
- Full explanation, including how to save, export, share and make your own packs: [Tunes: user manual](../docs/tunes/USER-MANUAL_EN.md). The basics of Patchkamer: [main manual](../docs/USER-MANUAL_EN.md).

## File format

One pack per file, named `name.patchkamer-tunes.json`: JSON with `format` (`patchkamer-tunes`), `formatVersion` (1), `device` (the exact id of the device), `name`, `author`, `license`, `description` and a `tree`. The `tree` holds folders (`folder` with `items`) and tunes; every item has a `name`, `kind: "set"` and the device's own `state`. Rules for agents that write packs: [AGENTS.md](AGENTS.md).
